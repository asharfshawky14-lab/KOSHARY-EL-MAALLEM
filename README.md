# كُشري المعلم — المرحلة الأولى

مشروع ويب ثلاثي الأبعاد قابل للتشغيل محليًا أو عبر GitHub Pages.

## الموجود في هذه النسخة
- شارع مصري ثلاثي الأبعاد مع أرصفة ومبانٍ متعددة الطوابق ونوافذ وشرفات وأعمدة إنارة وأشجار.
- واجهة محل كشري باسم «كُشري المعلم» مع زجاج وباب ولافتة ومطبخ وصالة وكاشير ومعدات.
- شخصيات بشرية مبنية بأجزاء جسم وملابس ووجه وأطراف متحركة، وليست مكعبات.
- سيارة وموتوسيكل بتفاصيل أساسية.
- منظور أول، حركة وتصادمات أساسية، جري، تحريك كاميرا بالماوس أو اللمس.
- عصا تحكم للموبايل وزر تفاعل وزر جري.
- تفاعل فعلي مع الباب والكاشير يعرض حالة النظام الحالية بوضوح.
- إيقاف مؤقت واستكمال وحفظ محلي للموقع والرصيد.

## التشغيل
لأن المشروع يستخدم JavaScript Modules، شغّله من استضافة تدعم HTTPS مثل GitHub Pages، أو عبر خادم محلي.

### GitHub Pages
1. ارفع كل محتويات المجلد إلى مستودع GitHub.
2. افتح Settings ثم Pages.
3. اختر Deploy from a branch، ثم الفرع الرئيسي والجذر `/`.
4. افتح رابط Pages بعد اكتمال النشر.

### ملاحظات مهمة
- يلزم اتصال بالإنترنت لتحميل Three.js والخط العربي من CDN في هذه النسخة.
- يفضل فتح اللعبة في Chrome أو متصفح حديث يدعم WebGL.
- هذه حزمة تأسيسية للمرحلة الأولى وليست اللعبة النهائية بكل أنظمة الطبخ والزبائن والاقتصاد والدليفري.
- أنظمة الكاشير والطبخ والطلبات لم تُعلن كأنها مكتملة؛ عناصرها موجودة مكانيًا وسيتم ربطها بمنطق اللعب في مراحلها.
- المجسمات الحالية مصنوعة برمجيًا من أشكال ثلاثية الأبعاد مركبة ومحسّنة للأداء. للحصول على واقعية أعلى لاحقًا، يمكن إضافة نماذج GLB مرخصة ومخصصة دون تغيير هيكل الأنظمة.
